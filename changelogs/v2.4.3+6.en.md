## Changelog
 - Check Update asks before it downloads, showing what is new and the download size
 - A release with new features is offered once when the app opens, to update now, later, or skip that version
 - Long-press a playlist to select several and delete them at once; it asks first, and the videos in them stay
 - Unfriending asks first instead of happening on a single tap
 - The profile description is edited in an outlined multi-line box; saving the name or description says "Saved" once the site has it
 - In selection mode the back key leaves the selection first instead of the page

## Attention
 - Only the Android app is maintained.
