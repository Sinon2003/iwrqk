## Changelog
 - Preferred quality in App settings: auto, best quality, smoothest, or a fixed resolution that falls back to the next one below
    - Auto plays the best resolution your connection handled smoothly, measured while videos play, without using extra data
    - Picking a resolution in the player now only changes that video
    - Fix videos starting at the lowest resolution
 - Check Update downloads the new version in the app and opens the installer, instead of the release page in a browser
 - History shows Cloud and This device tabs: what your account watched on every device, and this device's history, which can be searched and cleared
 - Account settings: switches and fields save as you change them, without a loading dialog or a "saved" message
 - "Settings" in the drawer is now "App settings", to tell it apart from "Account settings"
 - Remove the iOS project
