## 更新内容
 - 新的应用 ID `com.iwrqk.app.sinon`，可以和原版应用同时安装
 - 账号
    - 账号设置：修改头像、背景图、昵称和简介，隐藏敏感内容，选择接收哪些通知
    - 通知页面，侧边栏显示未读数
    - 私信：查看和回复会话，从个人主页发起会话，删除自己发的消息
    - 自己的主页有"编辑资料"按钮，主页菜单可以复制链接或在浏览器中打开
    - 账号在网站上的观看记录，包含所有设备（历史记录页的云图标）
    - 会员可以屏蔽用户，并管理已屏蔽的用户
 - 可以删除播放列表
 - 看视频会像网页端一样计入播放量
 - 论坛
    - 删帖前需要确认
    - 楼主可以修改标题或删除自己的主题
 - 翻译
    - 可选翻译源：Google（默认）、火山、腾讯交互翻译、Yandex
    - 在设置里选择默认翻译源和启用的翻译源
    - 长按翻译按钮可以换一个翻译源翻译
    - 译文默认替换原文，点"显示原文"切换回去；也可以在设置里改成显示在原文下方
    - 视频简介、评论和论坛帖子里的译文可以收起
    - 修复长文本翻译失败
 - 搜索历史
    - 长按后每一项显示删除按钮，不再直接删除
 - 下载
    - Android 10：可以下载到自选的文件夹
 - 实验性功能：加速下载与播放（设置 → 实验性功能）。视频分成多段同时获取，适合单个连接速度慢的线路
 - 检查更新改为使用本项目的 Release
 - 复制标签、评论或下载链接时会有提示
 - 修复侧边栏打开时按返回键提示退出，而不是关闭侧边栏
 - 修复繁体中文在首次启动后变成简体中文
 - 修复用户搜索和关注列表在包含已注销账号时加载失败，这类账号现在显示为"已注销用户"
 - 修复楼主的帖子上不显示"楼主"标记
 - 修复"相关度"的繁体中文文案（原先是日文）
 - 升级到 Flutter 3.47.5 并更新依赖

## 注意
 - 目前只维护 Android 版，其他平台仍沿用原项目的代码，未经测试。
 - 由于应用 ID 变了，这是一个独立的应用：不会覆盖原版，数据和登录状态需要重新开始。
 - 开启加速下载后，请保持应用运行直到下载完成。
