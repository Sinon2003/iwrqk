## Changelog
 - New app ID `com.iwrqk.app.fork`, so it can be installed alongside the original app
 - Translation
    - Choose the source: Google (default), Volcengine, Tencent TranSmart or Yandex
    - Set the default source and the enabled sources in Settings
    - Long-press the translate button to translate with another source
    - Translations can be collapsed in video descriptions, comments and forum posts
    - Fix long text failing to translate
 - Search history
    - Long-press shows a delete button on every item instead of deleting the item at once
 - Download
    - Android 10: downloads can be saved to the chosen folder
 - Check for updates uses this project's releases
 - Fix the Traditional Chinese text of "Relevance" (it was Japanese)
 - Upgrade to Flutter 3.47.5 and update dependencies

## Attention
 - Only the Android app is maintained for now. The other platforms still use the original project's code and have not been tested.
 - Because of the new app ID, this is a separate app: it does not replace the original one, and data and login start fresh.
